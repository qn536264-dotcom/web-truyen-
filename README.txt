WEB TRUYỆN CƠ BẢN

1. Mở index.html để xem trang chủ.
2. Vào chapters/chapter-1/.
3. Cho ảnh truyện vào thư mục chapter-1.
4. Mở index.html của chapter và thêm:
   <img class="page" src="001.jpg">
   <img class="page" src="002.jpg">
   ...
5. Muốn thêm chapter: copy thư mục chapter-1, đổi tên thành chapter-2 rồi sửa nội dung.

Đây là bản web tĩnh: không cần database, đăng nhập hay code server.
